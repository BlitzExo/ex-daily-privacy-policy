Privacy Policy

EX Daily Upload Tool ("aplikasi ini") adalah aplikasi internal milik pengguna pribadi yang digunakan semata-mata untuk mengotomatiskan proses unggah video ke akun YouTube milik pengguna sendiri (channel "EX Daily"). Aplikasi ini tidak digunakan oleh pihak ketiga dan tidak mengumpulkan atau membagikan data pengguna lain mana pun.

Data yang Diakses

Aplikasi ini mengakses YouTube Data API v3 dan YouTube Analytics API, terbatas pada akun Google pemilik aplikasi sendiri, untuk:

  • Mengunggah video ke channel YouTube milik pemilik aplikasi
  • Mengatur metadata video (judul, deskripsi, thumbnail, playlist, jadwal tayang)
  • Membaca statistik channel dan video milik pemilik aplikasi (views, watch time, komentar)
  • Membaca dan memoderasi komentar pada video milik pemilik aplikasi sendiri

Penggunaan Data

Semua data yang diakses digunakan hanya untuk keperluan operasional pemilik aplikasi sendiri (manajemen konten channel pribadi). Data tidak pernah dijual, dibagikan, atau digunakan untuk tujuan selain yang disebutkan di atas.

Penyimpanan Data

Token akses OAuth disimpan secara lokal di perangkat pemilik aplikasi dan tidak dikirim ke server pihak ketiga mana pun.
